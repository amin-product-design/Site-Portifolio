Статический сайт-визитка. Чистый HTML/CSS/JS, без бэкенда, без форм с отправкой данных — всё, что нужно, это открыть `index.html`.

## Структура

```
index.html      — разметка страницы
styles.css      — все стили
script.js       — отзывы, мобильное меню, мелкие интерактивы
```

## Как посмотреть локально

Просто откройте `index.html` в браузере — двойным кликом. Либо, если есть Python:

```bash
python3 -m http.server 8000
```

и зайти на `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `portfolio`.
2. Загрузите в него файлы `index.html`, `styles.css`, `script.js` и папку `assets` (если будет) — либо через веб-интерфейс (Add file → Upload files), либо через git:
   ```bash
   git init
   git add .
   git commit -m "Первая версия сайта"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/portfolio.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages**.
4. В блоке **Build and deployment → Source** выберите **Deploy from a branch**.
5. Branch: `main`, папка: `/ (root)` → **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/portfolio/`

Эту ссылку уже можно скидывать — она рабочая и постоянная.

## Подключение своего домена

Когда купите домен (Reg.ru, Namecheap, Cloudflare — не важно):

1. В репозитории **Settings → Pages → Custom domain** впишите ваш домен (например `amin-design.com`) и сохраните — GitHub сам создаст файл `CNAME` в репозитории.
2. У регистратора домена (в панели управления DNS) добавьте записи:
   - Если домен вида `amin-design.com` (без www), добавьте 4 записи **A** на IP-адреса GitHub Pages:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - Если хотите использовать поддомен, например `www.amin-design.com`, добавьте запись **CNAME**:
     ```
     www → ВАШ_ЛОГИН.github.io
     ```
3. Подождите от 10 минут до нескольких часов (обновление DNS).
4. Вернитесь в **Settings → Pages** и включите **Enforce HTTPS** — GitHub бесплатно выпустит SSL-сертификат.

Готово — по домену будет открываться ваш сайт.
